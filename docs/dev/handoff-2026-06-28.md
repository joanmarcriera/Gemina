**Step 1 — stand up a data+exit gateway** (the draft deploy; validate it as you go):
```bash
scripts/deploy-dev-gateway.sh                       # build the image on oracle
ssh oracle 'cd /opt/gemina && sudo WAN_IF=<egress-iface> scripts/setup-exit-host.sh'
ssh oracle '
  sudo install -m0644 /opt/gemina/deploy/systemd/gemina-gateway-data.service \
       /etc/systemd/system/gemina-gateway-data.service
  sudo systemctl daemon-reload && sudo systemctl enable --now gemina-gateway-data.service'
ssh oracle 'sudo journalctl -u gemina-gateway-data.service | grep public_key | tail -1'
```
Find `<egress-iface>` with `ssh oracle 'ip route show default'` (the `dev` name).
Then open ingress **UDP 51820** in the Oracle Cloud VCN (console, not the host).
Copy the printed **base64 Ed25519 `public_key`** — the app pins it. In open mode
(default) the token is ignored, so host + key is all the app needs.

> uid owning the persistent TUN (`CONTAINER_UID`, default 65532), the firewall
> backend (script handles nft and iptables), and whether `--network host` + the
> VCN both allow UDP 51820. Fixes you make here should be committed back over the
> DRAFT headers. This also closes issue **#5** (egress deploy hardening) — add a
