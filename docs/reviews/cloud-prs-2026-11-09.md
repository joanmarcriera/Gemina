   endpoint send, not per packet. A packet delivered on the healthy path still
   adds one "drop" when the other path fails.

   (`/proc/sys/net/ipv4/ip_forward`, `net.Interfaces()`). They pass here and in
   CI but could flake on a host whose interfaces change mid-run.
